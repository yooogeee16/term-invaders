# TERM INVADERS｜応用情報 用語暗記アプリ

応用情報技術者試験シラバス（Ver.7.2）に掲載された用語4,747語を収録した、非公式の学習アプリです。

## 🔗 公開URL

**https://yooogeee16.github.io/**

インストール不要・登録不要、ブラウザで開くだけで遊べます。

## 特徴

- **4,747語**を全大分類（基礎理論〜企業と法務）にわたって収録
- **クラシックモード**：4択クイズ（用語→意味／意味→用語／ミックス、苦手優先モードあり）
- **シューティングモード**：インベーダー風に敵を撃ち落としながら暗記
- **DOPAシューティングモード**：コンボが伸びるほど画面が沸騰するハイテンポ版（1ミスで即終了）
- **分析タブ**：大分類別の学習状況、苦手な用語ランキング
- レベリング要素（正解でXPを獲得し、自機がグレードアップ）
- 効果音・BGM風の演出（Web Audio APIで生成、外部音源不使用）
- 学習履歴はすべてブラウザの `localStorage` に保存（サーバー送信なし）

## このアプリについて

本アプリは個人が作成した非公式のファンメイド教材です。独立行政法人情報処理推進機構（IPA）およびIPAが実施する試験制度とは一切関係ありません。詳細はアプリ内の「ⓘ」ボタンからご確認ください。

## 技術構成

単一の `index.html` に HTML / CSS / JavaScript を完結させた自己完結型のアプリです。外部ライブラリ・CDN・フォントは使用していません。ビルド用のスクリプトやシラバスからの用語抽出ロジックは `scratch/` 以下にあります（デプロイには不要）。
